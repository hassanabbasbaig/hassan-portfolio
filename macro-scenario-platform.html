Problem

Macroeconomic scenarios are often assembled across models, spreadsheets, data vintages and judgemental assumptions. That makes it difficult to establish exactly which inputs and model choices produced a published scenario—or whether an earlier approval is still valid after something upstream changes.

What I built

A research-grade scenario-platform concept connecting data vintages, model estimation, scenario assumptions, shocks, analytical outputs and release governance in a reproducible workflow.

The design separates an authoritative modelling core from an economist-facing workbench and downstream consumers through explicit, versioned interfaces.

Design principle

Objective
Institutional reproducibility
Governance
Fail closed

Reproducible computationally—and institutionally.

A scenario release should preserve the relationship between the exact data, calibration, model specification, scenario assumptions, validation state and approval that produced it.

If an upstream input changes, downstream approval should no longer be treated as valid. The design therefore avoids stale fallback and implicit approval reuse.

Methods & technology

Economics first; software as analytical infrastructure.

The project is intended to demonstrate system design around an economist's workflow rather than present a web interface as the analytical contribution.
